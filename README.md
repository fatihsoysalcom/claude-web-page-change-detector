# Claude Web Page Change Detector

This Python script monitors a specified web page for changes. It periodically fetches the page content, calculates a hash of the content, and alerts if the hash differs from the previous check, indicating a change. This demonstrates a basic form of web page proof-of-change.

## Language

`python`

## How to Run

1. Save the code as `web_monitor.py`.
2. Replace `https://example.com` with the URL you wish to monitor.
3. Run from your terminal: `python web_monitor.py`
